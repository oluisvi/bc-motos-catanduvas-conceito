# BC Motos — conceito de vitrine digital

Estudo demonstrativo para apresentar um caminho complementar aos canais que a BC já mantém. Feito com HTML, CSS e JavaScript sem dependências de build.

## Designs
- Estrada: editorial orgânico, foco no triciclo Sky Run e sensação de mobilidade em grupo.
- Cidade: estrutura modular e clara, navegação direta por categorias.
- Família: narrativa centrada em pessoas e no triciclo de três lugares.

## Funcionalidades
